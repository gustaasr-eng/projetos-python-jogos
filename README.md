# 🎮 Projetos em Python: Jogo da Velha com IA e Jogo da Forca

Repositório criado para armazenar os projetos práticos desenvolvidos na disciplina de **Algoritmos e Programação** do curso de **Engenharia de Software** no UniAcademia.

## 🛠️ Destaques Técnicos e Lógica Utilizada
- **Modularização de Código:** Organização do programa em funções (`def`) para reutilização e clareza.
- **Lógica e Tomada de Decisão (IA Básica):** Algoritmo no Jogo da Velha que analisa o tabuleiro para vencer, bloquear jogadas do adversário ou priorizar posições estratégicas (centro e cantos).
- **Estruturas de Dados:** Manipulação de listas/vetores para representação de tabuleiros e histórico de jogadas.
- **Validação de Entradas:** Controle de erros do usuário via laços `while` para impedir jogadas inválidas.

## 🚀 Como Executar os Jogos
Com o **Python 3** instalado, basta executar no terminal:
- `python jogo_da_velha.py`
- `python jogo_da_forca.py`
