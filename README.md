# 🎮 Projetos em Python: Jogo da Velha e Jogo da Forca

Repositório criado para armazenar os projetos práticos desenvolvidos na disciplina de **Algoritmos e Programação** do curso de **Engenharia de Software** no UniAcademia.

## 🛠️ Conceitos Utilizados
- **Linguagem:** Python
- **Lógica de Programação:** Laços de repetição (`while`, `for`), estruturas condicionais (`if/elif/else`).
- **Estruturas de Dados:** Listas, matrizes e manipulação de strings.
- **Funções:** Modularização do código em rotinas reutilizáveis.

## 🚀 Como Executar os Jogos
Basta ter o **Python 3** instalado na máquina e executar os arquivos pelo terminal/prompt de comando:
- `python jogo_da_velha.py`
- `python jogo_da_forca.py`
